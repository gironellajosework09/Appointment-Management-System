A few helpful answers.

Do I need an account to book?

No. This concept keeps an account-free guest path available. An account is optional where enabled.

Can I review before sending?

Yes. The proposed journey includes a final review before an explicit submission.

Is this a real booking service?

No. This is an isolated fictional prototype. It does not create or change appointments, send messages, or verify identity.
